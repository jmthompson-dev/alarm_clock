# ⏰ Alarm Clock
This Python program calculates the time an alarm will go off, based on the current time and a user-defined wait period.

### 📋 Description
The user enters:

- The current time in 24-hour format (0–23)

- The number of hours to wait before the alarm goes off

The program then calculates the future alarm time using modulo 24 to wrap around the clock.
